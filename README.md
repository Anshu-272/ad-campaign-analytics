# Ad Campaign Analytics — SQL Project

## Project Overview
This project analyzes digital advertising campaign performance using SQL. The report explores campaign engagement, audience behavior, ad formats, platform performance, and purchase conversions to identify business insights and opportunities for improvement.

## Project Objectives
- Analyze advertising campaign performance.
- Compare engagement across advertising platforms and formats.
- Examine audience demographics and behavior.
- Evaluate clicks and purchase conversions.
- Develop data-driven recommendations for marketing decisions.

## Dataset Overview
The report describes four relational tables:

- **Campaigns:** Campaign names, dates, duration, and budget.
- **Ads:** Advertising information and formats.
- **Users:** Audience and demographic information.
- **Ad Events:** Recorded interactions, including impressions, clicks, likes, comments, shares, and purchases.

The report describes a dataset of 50 campaigns, 200 advertisements, 10,000 users, and over 400,000 ad events.

## Tools and Skills
- SQL
- Relational database analysis
- Data aggregation and filtering
- Joins and subqueries
- Conditional logic using `CASE WHEN`
- Ranking and window functions
- Marketing KPI analysis
- Business reporting and recommendations

## Business Questions
- Which campaigns generate the most engagement?
- Which advertising formats perform best?
- How does performance vary across platforms?
- Which campaigns have higher click-through and purchase rates?
- How do audience characteristics relate to engagement?
- What opportunities exist to improve advertising performance?
